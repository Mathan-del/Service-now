# Auto Ticket Classification using Flow Designer

## Problem Statement
The school IT helpdesk receives multiple incident requests daily from students and teachers, such as Wi-Fi issues, projector failures, password problems, and slow computers.

Currently, IT staff manually review each request and assign a category, which is time-consuming and inefficient.

This project automates ticket classification using ServiceNow Flow Designer by analyzing keywords in the incident's short description and description fields.

## Objective
- Automatically classify incidents at the time of creation.
- Reduce manual effort for IT agents.
- Improve ticket routing efficiency.
- Implement a no-code, easily maintainable solution.
