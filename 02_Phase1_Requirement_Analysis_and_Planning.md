# Phase 1: Requirement Analysis & Planning

The school IT helpdesk receives multiple support requests daily from students and teachers related to common issues such as network connectivity, hardware failures, account access problems, and system performance issues.

Currently, IT staff manually review each ticket to:
- Identify the issue type.
- Select the correct category and subcategory.
- Inform the caller about ticket creation.

This manual process is time-consuming, error-prone, and not scalable as the number of requests increases.

## Activity 1: Business Use Case

### Business Requirements
The system must:
- Automatically classify IT tickets based on the issue description.
- Assign both Category and Subcategory without manual intervention.
- Support dependent choice logic between Category and Subcategory.
- Send an automated email notification to the caller upon ticket creation.
- Store ticket information in a structured and standardized format.
- Ensure easy maintenance and future scalability.

## Activity 2: Creation of New Update Set

Navigation Steps:
1. Go to All menus → search for **Update set**.
2. Under System Update Sets → select **Local Update Sets**.
3. Click the **New** button on the top right corner.
4. Name: **Project Update Set**.
5. State: **In progress**.
6. Application: **Global**.
7. Save the form.
8. Under Related Links click **Make This My Current Set**.
9. The created Update Set will now appear as Current.
