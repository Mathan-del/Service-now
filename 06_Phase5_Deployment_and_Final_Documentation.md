# Phase 5: Deployment & Final Documentation

The objective of this phase is to deploy the developed solution to the target environment and finalize all project documentation.

It ensures the solution is stable, reusable, and ready for demonstration or production use, with complete and clear documentation for future reference.

## Activity 1: Make Update Set to Complete State
1. Go to All menus → search **Local Update Sets**.
2. Under System Update Sets select **Local Update Sets**.
3. Open **Project Update Set**.
4. Change State from **In progress** to **Complete**.
5. Save the form.
6. Under Related Links click **Export to XML**.
7. The update set is downloaded to your system in XML format.
8. The downloaded file can be shared through WhatsApp or Mail.
9. This is how the created update set is transferred to other instances.
